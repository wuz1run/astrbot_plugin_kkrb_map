# 三角洲地图密码与交易行（astrbot_plugin_kkrb_map）

查询《三角洲行动》每日地图密码和交易行行情，数据来自 [kkrb.net](https://www.kkrb.net/)。

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/地图密码` | `/三角洲密码` | 返回当日各图密码 |

输出示例：

```text
三角洲行动 地图密码（2026-11-25）
零号大坝：5764
长弓溪谷：5798
巴克什：5737
航天基地：5258
潮汐监狱：5727
AZ3：5751
更新时间：2026-11-25 00:00
数据来源：kkrb.net
```

## 交易行（v1.1.0）

默认关闭。获得站方的数据使用许可后，将 `market_enable` 设为 `true`。

| 指令示例 | 返回内容 |
| --- | --- |
| `/交易行` | 查看用法 |
| `/查价 M4A1突击步枪` | 单物品现价和数据时间 |
| `/交易行 曲线 国服 7天 M4A1突击步枪` | 近 3、7 或 15 天的历史价格走势和高低点 |
| `/交易行 联想 M4A1` | 匹配的完整物品名 |
| `/交易行 热门` | 热门查询物品及现价 |
| `/交易行 单格价值 医疗 第2页` | 收集品和消耗品的单格价值 |
| `/交易行 涨幅` | 24 小时收集物资涨幅前十 |
| `/交易行 子弹盈亏` | 子弹昨日理论盈亏和本周最高位盈亏 |
| `/交易行 活动需求` | 活动需求物品的现价和理想售价 |
| `/交易行 兑换利润` | 军需处兑换子弹的成本、总价和利润 |
| `/交易行 制造材料` | 材料现价和昨日高低点 |
| `/交易行 自选包` | 弹药自选包的数量、总价和利润 |

列表指令可带关键词和 `第2页` 这类页码。查价、曲线、热门、兑换利润、制造材料和自选包可指定 `国际服`，未指定时默认国服。

- **只在查询时刷新，不后台轮询。** 同一报表由所有会话共享 30 分钟内存缓存，筛选、翻页和切换报表区服不重复请求。
- 查价和曲线共用 30 分钟刷新间隔，联想单独计时。间隔内不同查询只返回已有缓存或提示稍后再试，不会新发请求。
- 收到限流响应后至少暂停 30 分钟，并遵守更长的 `Retry-After`。站点拒绝访问时停止交易行联网；单物品额度耗尽时停止查价和曲线联网。缓存和限流状态保留在插件进程内，不应用重载来绕过源站限制。
- 刷新失败时可返回旧行情，并标注数据时间及旧缓存状态。交易行不使用地图密码的代理配置。

## 地图密码缓存策略

- 按**北京时间**以天为键缓存；成功写入后，当天后续查询不再访问源站。
- 缓存文件在 `data/plugin_data/astrbot_plugin_kkrb_map/cache.json`，插件更新不会丢。
- 源站不可用时默认返回上一次成功的数据，并在回复里注明。
- 跨天后第一次查询会重新抓取。

## 地图密码实现要点

源站没有公开 API，抓取需要三步握手：

1. `GET /?viewpage=view%2Foverview`，从 cookie 取 `csrf_token`；
2. `POST /getMenu` 建立会话状态（跳过它时 `getOVData` 恒返回 `-101`）；
3. `POST /getOVData`，请求头带 `X-CSRF-Token`。

`kkrb.py` 包含完整实现，失败时用新会话重试一次。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `command_enable` | `true` | 是否启用地图密码指令 |
| `market_enable` | `false` | 是否启用交易行和查价指令 |
| `include_source` | `true` | 回复末尾是否带来源 |
| `request_timeout` | `15` | 请求源站超时（秒） |
| `proxy` | 空 | 仅供地图密码使用的连接代理 |
| `fallback_on_error` | `true` | 失败时返回旧缓存 |

## 注意

- 网页接口没有公开第三方契约；源站改版或限制访问时，插件可能无法刷新。
- 仅建议低频使用，不要改成高频轮询。
