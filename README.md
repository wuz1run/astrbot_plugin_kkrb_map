# 三角洲地图密码（astrbot_plugin_kkrb_map）

查询《三角洲行动》每日地图密码，数据来自 [kkrb.net](https://www.kkrb.net/)。

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/地图密码` | `/三角洲密码` | 返回当日各图密码 |

输出示例：

```text
三角洲行动 地图密码（2026-11-25）
零号大坝：5764
长弓溪谷：5798
巴克什：5737
航天基地：5258
潮汐监狱：5727
AZ3：5751
更新时间：2026-11-25 00:00
数据来源：kkrb.net
```

## 缓存策略

- 按**北京时间**以天为键缓存，同一天内无论多少群友查询都只请求源站一次。
- 缓存文件在 `data/plugin_data/astrbot_plugin_kkrb_map/cache.json`，插件更新不会丢。
- 源站不可用时默认返回上一次成功的数据，并在回复里注明。
- 跨天后第一次查询会重新抓取。

## 实现要点

源站没有公开 API，抓取需要三步握手：

1. `GET /?viewpage=view%2Foverview`，从 cookie 取 `csrf_token`；
2. `POST /getMenu` 建立会话状态（跳过它时 `getOVData` 恒返回 `-101`）；
3. `POST /getOVData`，请求头带 `X-CSRF-Token`。

`kkrb.py` 包含完整实现，失败时用新会话重试一次。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `command_enable` | `true` | 是否启用指令 |
| `include_source` | `true` | 回复末尾是否带来源 |
| `request_timeout` | `15` | 请求源站超时（秒） |
| `proxy` | 空 | 服务器访问不到源站时填代理，如 `http://127.0.0.1:7890` |
| `fallback_on_error` | `true` | 失败时返回旧缓存 |

## 注意

- 站点无公开文档，页面结构或鉴权方式变更可能导致抓取失败，此时日志里会记录具体原因。
- 仅建议低频使用，不要改成高频轮询。
